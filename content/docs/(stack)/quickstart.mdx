Add the Lightcone plugin to your coding agent, then start an analysis together.

<Callout title="Before you start">
  You'll need Linux or macOS (WSL on Windows), Claude Code or Codex, and
  [uv](https://docs.astral.sh/uv/) 0.12 or newer. Your agent can guide you through setting up uv
  if you don't have it yet.
</Callout>

<Steps>
<Step>

## Install the Lightcone plugin

The plugin teaches your agent to use Lightcone. When you start a project, it checks for the
Lightcone CLI and offers to install the right version.

## Install a UI (optional)

Much of what Lightcone records is meant to be read in a UI: the decisions in the analysis and the
alternatives they were weighed against, the results it produces, which decisions each result depends
on, and the findings and the papers behind them. All of it lives in the project's `astra.yaml`,
which is easy for an agent to read but hard for a person. You can work without a UI if you prefer,
but we recommend one.

[Lightcone Lab](/lightcone-lab) is a JupyterLab extension, for JupyterLab 4.5.10 or newer. Start
JupyterLab however you usually do, open the **Extension Manager** (the puzzle piece in the left
sidebar), search for `jupyterlab-lightcone` and install it. Then restart JupyterLab.

Or install JupyterLab and Lightcone Lab together with uv, then start it:

```bash
uv tool install jupyterlab --with "jupyterlab-lightcone[full]" --with-executables-from jupyter-core
jupyter lab
```

## Start your first analysis

1. **Create a project.** In Lightcone Lab, choose **New Lightcone project** in JupyterLab's launcher;
   Lab sets it up and opens its **Home**. Without Lab, make a new directory for your analysis.
2. **Launch your agent** in the project's directory.
3. **Give it your research question**, using the Lightcone skill:

<Tabs groupId="agent" persist defaultValue="claude-code">
<TabsList>
  <TabsTrigger value="claude-code">Claude Code</TabsTrigger>
  <TabsTrigger value="codex">Codex</TabsTrigger>
  <TabsTrigger value="opencode" disabled>OpenCode (soon)</TabsTrigger>
</TabsList>
<TabsContent value="claude-code">

```text
/lightcone:lightcone I want to start a new analysis: <your research question>
```

</TabsContent>
<TabsContent value="codex">

```text
$lightcone:lightcone I want to start a new analysis: <your research question>
```

</TabsContent>
</Tabs>

From there, the agent:

1. **Interviews you** about the research question and the structure of the analysis, before it
   writes any code.
2. **Sets up the project** with `lc init`, if Lab hasn't already: the specification
   (`astra.yaml`), a uv environment, a git repository whose data and results are stored with
   git-annex, and a MyST report.
3. **Writes the analysis down** in `astra.yaml` (its inputs, outputs, decisions and evidence), which
   is validated each time it is saved, and shows you a summary.
4. **Implements and runs it** once you agree, with the Lightcone CLI: each step runs in a sandbox, and
   each output is committed with a record of how it was made.

For a worked example, follow [Your first analysis](/guides/first-analysis).

</Step>
<Step>

## Work through your analysis

Work through the analysis however you usually would with your agent. It already knows how to use
Lightcone and ASTRA, and it keeps the project's record up to date as you go; ask it at any point
what has changed, or what is out of date. We recommend keeping Lightcone Lab open alongside, so you
can follow the changes as they're made and explore how the pieces of the analysis fit together.

</Step>

## Uninstall

If you've chosen to uninstall Lightcone, we're sad to see you go.

<Tabs groupId="agent" persist items={['Claude Code', 'Codex']}>
<Tab value="Claude Code">

```bash
claude plugin uninstall lightcone@lightcone-research
claude plugin marketplace remove lightcone-research
uv tool uninstall lightcone-cli
```

</Tab>
<Tab value="Codex">

```bash
codex plugin remove lightcone@lightcone-research
codex plugin marketplace remove lightcone-research
uv tool uninstall lightcone-cli
```

</Tab>
</Tabs>

To remove Lightcone Lab, uninstall `jupyterlab-lightcone` from JupyterLab's Extension Manager, or
run `uv tool uninstall jupyterlab` if you installed it with uv. Your projects are left as they are:
everything Lightcone knows about an analysis lives in the project's own git repository.
