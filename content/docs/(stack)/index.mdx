Your AI agent can write and run an analysis faster than you can check it. Before you publish the
result, you need to know which choices went into it, and to be able to run it again when a referee
asks.

The Lightcone Stack keeps that record for you. The agent asks before it writes code: you make the
scientific choices, and it writes each one down with the evidence behind it. Each result comes from
a recorded run, so you or a collaborator can trace a figure back to the decisions that shaped it,
and reproduce it months later.

The stack works with Claude Code and Codex, on your own code and data.

## How it works

Each tool in the stack works on your project's git repository, where `astra.yaml` describes the
analysis in [ASTRA](/astra). The Lightcone CLI reads that file, runs the analysis and commits each
result next to it with a record of how it was made. Lightcone Lab, MySTRA and the Agent Skills read
the same file and the same records, and share nothing else. You can use any one of them without the
others, or replace it with your own.

We kept the tools separate so you can add them to a project you already have. Your group has its own
code and its own way of writing papers, and you shouldn't have to move either into a new system to
start. Begin by writing the specification with your agent and running it with the CLI; add Lab or
MySTRA later if you want them. The specification is plain YAML with an open schema, so any tool can
read it, including one you write.
