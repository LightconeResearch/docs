The Lightcone Stack is a sidecar for your research: it attaches to the project you're working on and
to the agent you already use, stays out of the way of how you work, and makes sure your work is
rigorous and reproducible by default. As you work, it keeps track of three things for you:

- **Every decision, and why.** The methodological choices you make are written down with the options
  you considered, the reasons for the choice, and the papers that informed it.
- **Every result, and what made it.** Each result carries a record of the code, data and environment
  that produced it, and anything made outside that record is flagged.
- **What a change affects.** When a decision or the data changes, you can see which results are out
  of date, and why.

We're not prescriptive about how much you use AI in your research: use an agent for everything, for
some things, or not at all. Our goal is to make sure that the science you do, however you do it, is
rigorous and reproducible.

<Callout type="warn" title="Public beta">
  The Lightcone Stack is in a **public beta**: expect some breaking changes between minor versions.
  Bug reports, design challenges and use cases we don't cover yet are exactly what we want to hear.
  Please [open an issue](https://github.com/LightconeResearch/lightcone-cli/issues).
</Callout>

## Components

Lightcone is deliberately built as a vertical stack of interoperable components. To see how it
works in detail, read [How it works](/how-it-works). To learn more about a specific component, pick
one below; they're listed from the bottom of the stack up.

- **[ASTRA](/astra)** is the specification the analysis is written in: its inputs, outputs,
  decisions and evidence, in `astra.yaml`.
- **[Lightcone CLI](/lightcone-cli)**, `lc`, runs every recipe in a sandbox and records the
  provenance of every output.
- **[MySTRA](/mystra)** lets the report cite the analysis by path: re-run the analysis and the
  report follows.
- **[Lightcone Lab](/lightcone-lab)** is a JupyterLab workbench for the project: its inventory,
  pipeline, provenance and report.
- **[Agent Skills](/agent-skills)** teach Claude Code or Codex to scope, build, run and report on
  the analysis with you.
