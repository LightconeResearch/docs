The Lightcone Research Stack helps you work with a coding agent while keeping a record of the
analysis: the inputs, methodological choices, code and evidence behind its results.
Read [What is the Lightcone Stack](/what-is-lightcone) for how the tools fit together.

## Set up your tools

Follow [Installation](/installation) to install the Lightcone CLI and the `lightcone` agent plugin.
You need Linux or macOS (WSL on Windows), uv, git, and Claude Code or Codex.

## Start an analysis

Create a directory and open your agent there:

```bash
mkdir my-analysis && cd my-analysis
claude   # or: codex
```

Describe the question you want to answer:

```text
I want to start a new analysis: <your research question>
```

The agent asks about the data, expected outputs and methodological choices, then records them in
[`astra.yaml`](/astra) for you to review. Once you agree on the plan, it writes the code and runs
the analysis with `lc`. The CLI saves each output with a record of how it was produced.

If the agent does not load the skill, invoke `/lightcone:lightcone` in Claude or the Codex app,
or `$lightcone:lightcone` in the Codex CLI.
