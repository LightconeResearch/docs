The plugin is distributed from the
[LightconeResearch/agent-skills](https://github.com/LightconeResearch/agent-skills) repository,
which your agent adds as a plugin marketplace named `lightcone-research`.

<Steps>
<Step>

### Add the marketplace

This is a one-time step for each agent.

<Tabs groupId="agent" persist defaultValue="claude-code">
<TabsList>
  <TabsTrigger value="claude-code">Claude Code</TabsTrigger>
  <TabsTrigger value="codex">Codex</TabsTrigger>
  <TabsTrigger value="claude-app">Claude app</TabsTrigger>
  <TabsTrigger value="codex-app">Codex app</TabsTrigger>
</TabsList>
<TabsContent value="claude-code">

```bash
claude plugin marketplace add LightconeResearch/agent-skills
```

</TabsContent>
<TabsContent value="codex">

```bash
codex plugin marketplace add LightconeResearch/agent-skills
```

</TabsContent>
<TabsContent value="claude-app">

Open **Customize → Plugins → Add → Add marketplace → Add from repo** and paste
`https://github.com/LightconeResearch/agent-skills`.

</TabsContent>
<TabsContent value="codex-app">

Open **Plugins** from the arrow beside **Create** and add the `LightconeResearch/agent-skills`
marketplace.

</TabsContent>
</Tabs>

</Step>
<Step>

### Install the plugin

<Tabs groupId="agent" persist defaultValue="claude-code">
<TabsList>
  <TabsTrigger value="claude-code">Claude Code</TabsTrigger>
  <TabsTrigger value="codex">Codex</TabsTrigger>
  <TabsTrigger value="claude-app">Claude app</TabsTrigger>
  <TabsTrigger value="codex-app">Codex app</TabsTrigger>
</TabsList>
<TabsContent value="claude-code">

```bash
claude plugin install lightcone@lightcone-research
```

</TabsContent>
<TabsContent value="codex">

```bash
codex plugin add lightcone@lightcone-research
```

The first time Codex asks you to review the plugin's hooks, approve them: they are how the plugin
checks the agent's work.

</TabsContent>
<TabsContent value="claude-app">

In **Customize → Plugins**, choose **lightcone** from the `lightcone-research` marketplace.

</TabsContent>
<TabsContent value="codex-app">

Open **Plugins** from the arrow beside **Create**, then search for **lightcone** and install it.

</TabsContent>
</Tabs>

The plugin runs the [Lightcone CLI](/lightcone-cli/getting-started#install-the-cli). At the start of
each session, it checks for the CLI, and if it's missing or too old, your agent offers to install
the version it needs.

<Callout type="warn" title="Enable and reload before you go on">
  You may need to enable the plugin and reload it (`/reload-plugins` in Claude Code), or restart
  your agent, before the skill is available.
</Callout>

</Step>
<Step>

### Start a project

Start your agent in an empty directory and tell it what you want to find out:

```text
I want to start a new Lightcone analysis: <your research question>
```

The agent interviews you about the question and the structure of the analysis before it writes any
code, sets the project up with `lc init`, and writes the analysis down in `astra.yaml`. Once you
agree, it implements the analysis and produces the results with `lc`.
[The lightcone plugin](/agent-skills/lightcone) describes each stage.

</Step>
<Step>

### Pick up an existing project

Start your agent in the project's directory and ask where things stand:

```text
Where were we?
```

The agent checks the state of every output with `lc status` and summarizes it before asking what to
do next.

</Step>
</Steps>
