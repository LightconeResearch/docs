<Steps>
<Step>

### Install the plugin

Register the Lightcone marketplace, then install the `lightcone` plugin, which includes `astra`:

```bash tab="Claude Code"
claude plugin marketplace add LightconeResearch/agent-skills
claude plugin install lightcone@lightcone-research
```

```bash tab="Codex"
codex plugin marketplace add LightconeResearch/agent-skills
codex plugin add lightcone@lightcone-research
```

The plugin drives the Lightcone CLI, so install that too (`uv tool install lightcone-cli==0.5.0rc5`).
[Installation](/docs/agent-skills/installation) covers the desktop apps, installing `astra` on its own,
and what the plugins need at runtime.

</Step>
<Step>

### Start a project

Start your agent in an empty directory and tell it what you want to find out:

```text
I want to start a new analysis: <your research question>
```

The agent interviews you about the question and the structure of the analysis before it writes any
code, sets the project up with `lc init`, and writes the analysis down in `astra.yaml`. Once you
agree, it implements the analysis and produces the results with `lc`.
[The lightcone plugin](/docs/agent-skills/lightcone) describes each stage.

</Step>
<Step>

### Pick up an existing project

Start your agent in the project's directory and ask where things stand:

```text
Where were we?
```

The agent checks the state of every output with `lc status` and summarizes it before asking what to
do next.

</Step>
</Steps>

For a complete example, from a question to a report, follow
