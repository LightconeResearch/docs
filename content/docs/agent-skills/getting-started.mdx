Complete the [plugin installation](/agent-skills/installation) first. For a Lightcone analysis,
install `lightcone`; it includes ASTRA support and needs the
[Lightcone CLI](/installation#3-the-lightcone-cli).

## Start a project

Open your agent in an empty project directory and describe the question:

```text
I want to start a new analysis: <your research question>
```

The agent asks about your data, expected outputs and methodological choices. It sets up the project
with `lc init` and records the plan in `astra.yaml` for review before implementing it.
[The lightcone plugin](/agent-skills/lightcone#scoping-a-new-analysis) describes the scoping process.

For a worked example with data and prompts, follow [Your first analysis](/guides/first-analysis).

## Resume a project

Open your agent in the project's directory and ask:

```text
Where were we?
```

The agent reads the specification and project notes, checks the outputs with `lc status`, and
summarizes what needs attention. You can then ask for a specific change, another universe, a run,
or a report update.

If the skill does not load, use its [explicit invocation](/agent-skills#call-a-skill).
