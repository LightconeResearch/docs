Agent Skills give your coding agent instructions for working on the analysis. They use the open
[Agent Skills](https://agentskills.io) format and are packaged as plugins for Claude Code and Codex.

A **skill** tells the agent how to approach a task, such as scoping an analysis or writing
`astra.yaml`. A **hook** runs at a specific event, such as the start of a session or an agent's
file edit, and reports checks back to the agent.

## Choose a plugin

| Plugin | Use it for |
| --- | --- |
| `lightcone` | Scoping, implementing, running and writing up a Lightcone analysis. Includes the `astra` skill and hooks. |
| `astra` | Writing and validating ASTRA specifications without the Lightcone CLI. |

Install `lightcone` for the full workflow. There is no need to install `astra` alongside it.
[Installation](/agent-skills/installation) covers both plugins and their requirements.

## Call a skill

Agents can load a skill when a task matches its description. You can also request it explicitly:

| Installed plugin | Skill | Claude Code, Claude app, Codex app | Codex CLI |
| --- | --- | --- | --- |
| `lightcone` | `lightcone` | `/lightcone:lightcone` | `$lightcone:lightcone` |
| `lightcone` | `astra` | `/lightcone:astra` | `$lightcone:astra` |
| `astra` | `astra` | `/astra:astra` | `$astra:astra` |

The skills guide the agent to review scientific choices with you, keep them in the specification,
and use the CLI to produce outputs. They are instructions to the agent; validation hooks check
files, but do not establish that an analysis is scientifically sound.
