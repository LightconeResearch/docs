title: The astra plugin
description: How an agent authors ASTRA specifications and checks their evidence.
---

The `astra` plugin gives an agent instructions for writing and revising `astra.yaml`. Install it
on its own for specification work, or use the copy included in the
[`lightcone` plugin](/agent-skills/lightcone). [ASTRA](/astra) explains the format and its purpose.

## Authoring a specification

The skill directs the agent to read `astra guide` before substantial authoring or restructuring,
and to consult `astra spec <term>` for field definitions. Those commands use the same tool version
as the validator:

```bash
uvx astra-tools@0.2.18 guide
uvx astra-tools@0.2.18 spec decision
```

The guidance covers which choices deserve named decisions, how to record alternatives and why they
were considered, and when to split work into sub-analyses. The agent validates its changes.
[Hooks](/agent-skills/hooks) describes the additional checks after supported agent edits and at
session start.

## Working with literature

For a claim supported by a paper, the skill directs the agent to:

1. Cache the paper with `astra paper add <doi>`, using `--version N` to pin an arXiv revision.
2. Copy the supporting passage from the cached PDF, with surrounding text when needed to identify
   the right occurrence.
3. Verify the quote with `astra paper verify-quotes <doi>` or
   `astra validate astra.yaml --verify-evidence`, using the pinned `uvx` command.
4. Correct a failed quote or leave it out, and report anything that could not be verified.

A matching quote establishes that the text appears in the source. You still need to assess whether
it supports the claim. Artifact-backed evidence is currently skipped by the quote verifier,
including when the output file exists; artifact quote verification is not implemented.

## Tool versions and invocation

The plugin pins `astra-tools` so its guidance and validator agree. It uses `uvx` instead of a bare
`astra` command that might point to another version. See
[plugin requirements](/agent-skills/installation#uv) for setup and
[skill invocation](/agent-skills#call-a-skill) to call the skill explicitly.

For commands beyond the authoring workflow, use the
[ASTRA CLI reference](https://astra-spec.org/latest/cli/).
