title: Overview
description: Run ASTRA recipes and keep a record of how each output was made.

---

The Lightcone CLI, `lc`, runs the recipes in `astra.yaml`. It resolves their dependencies,
executes them on a local or Slurm compute allocation, and commits each output with a manifest
recording its inputs, decisions and environment. git-annex stores the data and result files.

When you rerun an analysis, `lc` checks the outputs and rebuilds those whose definitions or inputs
have changed. It runs the universes you define. See [Core concepts](/lightcone-cli/concepts) for
output states and [ASTRA](/astra#decisions-and-universes) for decisions and universes.

You can drive `lc` yourself, use it in scripts, or let an agent with the
[`lightcone` plugin](/agent-skills/lightcone) run it. Commands do not prompt for input, and most
offer JSON output through `--json`.

<Callout title="Pre-release software">
The CLI is under active development and can change between releases. Follow the version in
[Installation](/installation#3-the-lightcone-cli), and report problems on
[GitHub](https://github.com/LightconeResearch/lightcone-cli/issues).
</Callout>
