The Lightcone CLI is an agent-native scientific workflow management system designed
to orchestrate the materialization of research artifacts declared in an `astra.yaml`
file while guaranteeing their provenance and reproducibility.

## What it does

- **Manages an ASTRA project.** `lc init` sets up `astra.yaml`, a locked uv environment and a git
  repository. Only the CLI writes results, each from the recipe `astra.yaml` declares for it, so every
  artifact traces back to the code, data and decisions that made it.
- **Runs the analysis.** `lc materialize` turns `astra.yaml` into a graph of tasks and runs each
  recipe in a sandbox, in parallel where it can, skipping outputs that are already up to date.
- **Versions and shares the data.** [git-annex](https://git-annex.branchable.com/) carries data and
  results alongside the code, so collaborators clone the project and fetch files with
  `git annex get` when they need them.
- **Certifies how each result was made.** Each output is committed with a manifest of its recipe,
  inputs and environment, and a run record that can replay it. Declare a license, and the CLI also
  maintains an [RO-Crate](https://www.researchobject.org/ro-crate/) ready to archive or deposit.
- **Gives your agent compute.** `lc compute launch` starts a [Dask](https://www.dask.org/) cluster,
  and `lc run` and `lc materialize` send it work. The commands are the same on a laptop and on a
  supercomputer.

Without a configuration file, the CLI uses your own machine. [Configuring compute](/lightcone-cli/configuring-compute)
sets up Slurm offers, and [HPC clusters](/clusters/nersc) gives ready configurations for known systems.
