Lightcone Lab is a JupyterLab extension, published as `jupyterlab-lightcone`. It displays the
analysis in `astra.yaml` as an inventory and a pipeline, with previews of figures, tables and cited
papers.

Browse into a project folder in JupyterLab's file browser. The launcher becomes the project's
**Home**, where you can open the inventory, inspect results or start an agent in the project
directory. The [Lightcone CLI](/lightcone-cli) runs the analysis and records its provenance.

## Choose an installation

The **workbench-only** installation uses JupyterLab's existing file and terminal services. It suits
a shared JupyterHub where you can add a user extension but cannot configure the server.

The **full** installation adds server features: output status, run history, committed versions,
comments, paper caching, report previews and Jupyter AI sessions. It suits a JupyterLab server you
manage.

[Installation](/lightcone-lab/installation) compares the requirements and commands.
The [workbench tour](/lightcone-lab/features) marks features that need the full installation.

Lightcone Lab is in early development; features and requirements can change between releases.
