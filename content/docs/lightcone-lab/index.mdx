Lightcone Lab is a JupyterLab extension for [ASTRA](/astra) projects. It shows a project's results,
the decisions behind them and the papers they cite, traces each result back to the run that made
it, and lets you work with an agent beside the analysis. The [Lightcone CLI](/lightcone-cli) runs the
analysis and records its provenance; Lab shows what it recorded.

Lab works on the project the file browser is in. Browse into a folder that holds an `astra.yaml`, and
the launcher tab becomes the project's Home: its title and description, its latest results, and a
way to start an agent.

![Lightcone Lab's Home for a reproduction of the GD-1 stream analysis: the project's title and description, counts of its results, decisions, inputs, findings and papers, a grid of its figures, and a panel of agent sessions.](<../(stack)/lab-home.png>)

## What it shows

In both installs, in the browser:

- **[Home](/lightcone-lab/features#home)**: the project's title page and latest results, with an
  agent or a terminal in the project folder one click away.
- **[Inventory](/lightcone-lab/features#inventory) and [pipeline](/lightcone-lab/features#pipeline)**:
  the analysis's outputs, decisions, inputs, findings and cited papers, with previews of figures and
  tables, and what feeds each result and what depends on it.
- **[Papers](/lightcone-lab/features#papers)**: each cited paper, opened at the quoted passage.
- **[Search](/lightcone-lab/features#search)**: <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>K</kbd> across
  records, files and commands.

With the [full install](/lightcone-lab/getting-started), the Jupyter server adds:

- **[Agent sessions](/lightcone-lab/agents)** in Jupyter AI, started at the project root, which show
  results as cards and list what each reply changed.
- **[Freshness](/lightcone-lab/features#freshness) and [provenance](/lightcone-lab/features#provenance)**:
  each result's `lc status`, the code, inputs and environment behind it, and its committed versions,
  side by side.
- **[Comments](/lightcone-lab/features#comments)** on figures, text and papers, which reach the agent
  with your next message.
- **[Report preview](/lightcone-lab/features#report)** of the project's [MySTRA](/mystra) report.

## How it fits the stack

- **[ASTRA](/astra)**: Lab reads the project's `astra.yaml`. Opening a project starts no kernel and
  changes no file.
- **[Lightcone CLI](/lightcone-cli)**: Lab sets up new projects with `lc init`, and shows the
  freshness, run records and versions that `lc` recorded. It never runs a recipe; you or your agent
  run `lc`.
- **[Agent Skills](/agent-skills)**: the **claude** and **codex** buttons on Home start the agent in
  a terminal in the project folder, where the `lightcone` plugin works as in any terminal.
- **[MySTRA](/mystra)**: with the full install, Lab previews the project's report in a tab.
