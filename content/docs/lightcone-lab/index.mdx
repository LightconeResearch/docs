---
title: Overview
description: A JupyterLab workbench for exploring and working on ASTRA projects.
---

Lightcone Lab is a JupyterLab extension that turns JupyterLab into a workbench for ASTRA projects:
a project home, an inventory of the analysis and its pipeline, provenance and version comparison,
comments, project-aware agents, and a viewer for the project's MySTRA report.

It runs as a browser-only workbench, or with its `full` extra for the features that need the
Jupyter server, such as running the Lightcone CLI and agents.
