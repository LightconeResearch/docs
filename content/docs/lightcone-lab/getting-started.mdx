Lab comes in three installs. The **workbench only** runs entirely in the browser, so it also works
in a JupyterLab whose environment you can't change, such as a JupyterHub at a computing center. The
**engine install** adds the features that run on the Jupyter server: each result's freshness and
provenance, project setup without a terminal, and the report preview. The **AI install** adds agent
sessions in Jupyter AI and comments on top. The [Workbench tour](/lightcone-lab/features) marks the
features that need each install.

<Steps>
<Step>

### Install Lab

<Tabs items={['Engine install', 'AI install', 'Workbench only']}>
<Tab value="Engine install">

Install JupyterLab with Lab, using [uv](https://docs.astral.sh/uv/):

```bash
uv tool install jupyterlab --with "jupyterlab-lightcone[engine]"
```

The engine install needs Linux or macOS, and git. Previewing a report also needs
[Node.js](https://nodejs.org/) 20 or newer.

</Tab>
<Tab value="AI install">

Install JupyterLab with Lab and Jupyter AI, using [uv](https://docs.astral.sh/uv/):

```bash
uv tool install jupyterlab --with "jupyterlab-lightcone[ai]"
```

The AI install needs what the engine install needs, and an agent adapter for each agent you want in
Jupyter AI (see [Work with an agent](#work-with-an-agent)).

</Tab>
<Tab value="Workbench only">

In JupyterLab 4.5.10 or newer, open the **Extension Manager** (the puzzle piece in the left sidebar),
search for `jupyterlab-lightcone`, install it, and restart JupyterLab. On JupyterHub, restart with
**File › Hub Control Panel › Stop My Server**, then start your server again.

The Extension Manager installs with pip, into the environment that runs JupyterLab, so it can't
install into a JupyterLab installed with uv. On a cluster's JupyterHub, see [HPC clusters](/clusters).

</Tab>
</Tabs>

</Step>
<Step>

### Start JupyterLab

With the engine or AI install, start JupyterLab with:

```bash
jupyter-lab
```

</Step>
<Step>

### Open or create a project

Browse the file browser into a folder that holds an `astra.yaml`: the launcher tab becomes the
project's **Home**. To start a new project, choose **New Lightcone project** in a launcher outside
any project, or run **Create project** from the command palette. In the workbench only, this runs
`lc init` in a terminal, so [install the Lightcone CLI](/lightcone-cli/getting-started#install-the-cli)
where JupyterLab's terminals can find it. See [New and existing projects](/lightcone-lab/features#projects).

</Step>
<Step>

### Find your way around

Home shows the project's title page, its results and a link to its pipeline. **Open ASTRA** opens
the inventory of the analysis, and <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>K</kbd> searches the project.
The [Workbench tour](/lightcone-lab/features) covers each feature.

</Step>
<Step>

### Work with an agent

Without Jupyter AI, in the workbench only or the engine install, the **claude** and **codex** buttons
on Home start an agent in a terminal, in the project folder. With the AI install, the **New session**
box starts a Jupyter AI session instead. Either way, add the [Agent Skills](/agent-skills/getting-started) plugin so the agent knows
how to work on a Lightcone project.

Jupyter AI talks to coding agents through [Agent Client Protocol](https://agentclientprotocol.com)
adapters, and none comes with Lab. For each agent you want in Jupyter AI, install the agent and sign
in, then install its adapter, which needs [Node.js](https://nodejs.org/) 22 or newer:

<Tabs groupId="agent" persist defaultValue="claude-code">
<TabsList>
  <TabsTrigger value="claude-code">Claude Code</TabsTrigger>
  <TabsTrigger value="codex">Codex</TabsTrigger>
</TabsList>
<TabsContent value="claude-code">

Install [Claude Code](https://code.claude.com/docs/en/setup) and run `claude` once to sign in. Then:

```bash
npm install -g @agentclientprotocol/claude-agent-acp
```

</TabsContent>
<TabsContent value="codex">

Install the [Codex CLI](https://developers.openai.com/codex/cli) and sign in with `codex login`. Then:

```bash
npm install -g @agentclientprotocol/codex-acp
```

</TabsContent>
</Tabs>

Restart JupyterLab, and the agent appears in the **New session** box's agent picker.
[Agents](/lightcone-lab/agents) covers sessions in detail.

</Step>
</Steps>

## Update and uninstall

For the engine or AI install:

```bash tab="Update"
uv tool upgrade jupyterlab
```

```bash tab="Uninstall"
uv tool uninstall jupyterlab
```

For the workbench only, use the Extension Manager. Your projects are untouched. The AI install
keeps its state inside each project, sessions in `chats/` and comments in `.lightcone/`; delete
those folders if you no longer want them.
