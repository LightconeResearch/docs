---
title: Overview
description: A MyST plugin for reports that reference an ASTRA analysis instead of copying it.
---

MySTRA is a plugin for [MyST](https://mystmd.org/) Markdown. A report written with it refers to
the parts of an ASTRA analysis, such as its decisions, results and values, by path instead of
copying them, so the report stays in step with the analysis. Projects created with `lc init` are
already set up to use it.
