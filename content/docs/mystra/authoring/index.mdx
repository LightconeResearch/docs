---
title: Authoring overview
description: "Reference any part of an ASTRA analysis with a path, inline with the {astra} role or as a block with the {astra} directive."
---

Use a [path](/mystra/authoring/paths) to identify an ASTRA record. A MyST *role* inserts a reference
inside a sentence; a *directive* places a block such as a figure or decision.

Your prose, equations and page structure use ordinary
[MyST Markdown](https://mystmd.org/guide/typography).

## Choose a reference [#choosing-a-surface]

| I want to… | Use | Example |
|---|---|---|
| Mention an element in a sentence | [`{astra}` role](/mystra/authoring/inline-references) | `` {astra}`decisions.algorithm` `` |
| Refer to a placed figure by number | Explicit `:label:` + MyST [`{ref}`](https://mystmd.org/guide/cross-references) | `` {ref}`fig-hubble` `` |
| Cite the literature behind an insight | [`{astra:cite}` / `{astra:cite:t}`](/mystra/authoring/inline-references#citations) | `` {astra:cite}`prior_insights.recon` `` |
| Put a measured number in prose | [`{astra:value}`](/mystra/authoring/live-values) | `` {astra:value col=alpha pm=true}`outputs.table` `` |
| Embed a figure, decision, finding, … as a block | [`{astra}` directive](/mystra/authoring/block-embeds) | `:::{astra} outputs.hubble_diagram` |
| Link to a placed block | its explicit [`:label:`](/mystra/authoring/block-embeds#cross-referencing-an-embedded-block) | `` {ref}`fig-hubble` `` |
| Split the report along sub-analyses | [Multi-page reports](/mystra/authoring/multi-page) | `reconstruction.md` |

## Keep results in sync [#the-golden-rule]

Reference measured values and selected options where possible, so rebuilding the report reads them
from the analysis. Explain their meaning in your prose, and review that interpretation whenever the
results change. A reference updates a value; it cannot update your scientific argument.

```markdown
# BAO from the ELG sample

## Method

We use {astra:value}`decisions.algorithm` for density-field reconstruction;
the {astra}`decisions.algorithm.multigrid` option follows
{astra:cite:t}`prior_insights.recon_sharpens_bao`.

:::{astra} decisions.algorithm
:::

({ref}`fig-bao`).

:::{astra} outputs.bao_fit_plot
:caption: Correlation function and best-fit model, post-reconstruction.
:label: fig-bao
:::

## Findings

:::{astra} findings
:::
```
